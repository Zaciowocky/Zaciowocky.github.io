# P0课上测试
这次考了一道组合逻辑电路与两道FSM

## T1 公共预约时间

三位同学要预约同一天的讨论室。每人提出一个限制：“不能早于某个时刻”或“不能晚于某个时刻”。请使用 Logisim 设计**组合逻辑电路**，输出同时满足三个限制的完整公共时间段。

当天可预约的时刻构成闭区间 $[0,T]$，其中 $T$ 表示当天结束时刻。时间均按无符号整数处理，本题不涉及跨天预约。

每个限制由一个时间 `time` 和一个方向信号 `dir` 组成：

| `dir` | 限制 | 对预约时刻 $t$ 的要求 |
| --- | --- | --- |
| `0` | 不能早于指定时刻 | $t\geq time$ |
| `1` | 不能晚于指定时刻 | $t\leq time$ |

三个限制必须同时满足，输入顺序不影响结果。

### 输入输出

| 名称 | 方向 | 位宽 | 含义 |
| --- | --- | ---: | --- |
| `time1`、`time2`、`time3` | 输入 | 各 5 位 | 三位同学指定的时刻 |
| `dir1`、`dir2`、`dir3` | 输入 | 各 1 位 | 对应限制的方向 |
| `lower` | 输出 | 5 位 | 公共时间段的最早时刻 |
| `upper` | 输出 | 5 位 | 公共时间段的最晚时刻 |

`lower` 应取所有“不能早于”时刻中的最大值；若没有这类限制，则取 $0$。`upper` 应取所有“不能晚于”时刻中的最小值；若没有这类限制，则取 $T$。因此，所有满足要求的时刻恰好构成闭区间 $[lower,upper]$。

输入保证各时间都在当天可预约范围内，且三个限制的交集具有正长度，即 `lower < upper`；无须处理无解或交集只有一个时刻的情况。

例如，三个限制分别为“不能早于 8”“不能晚于 20”“不能早于 12”，则公共时间段为 $[12,20]$，应输出 `lower=12`、`upper=20`。

### 我的思路

大意就是输入time1，dir1，time2，dir2，time3，dir3，

直接大的里面选最小的，小的里面选最大的就行

## T2 串行序列检测器

请设计一个**同步有限状态机**，逐位接收串行输入，检测连续比特串 `1101`。输入顺序按时间先后理解：每个时钟上升沿采样一位 `din`，最近四次采样依次为 `1、1、0、1` 时，完成一次检测。

### 输入输出

模块名为 `main`。

| 名称 | 方向 | 位宽 | 含义 |
| --- | --- | ---: | --- |
| `din` | 输入 | 1 位 | 当前接收的比特 |
| `clk` | 输入 | 1 位 | 在上升沿采样 `din` |
| `reset` | 输入 | 1 位 | 高电平有效的同步复位 |
| `hit` | 输出 | 1 位 | 本次采样是否刚完成一次 `1101` 检测 |
| `count` | 输出 | 2 位 | 已检测到的次数，最多计到 3 |

当一次采样刚好完成 `1101` 时，`hit` 在该时钟周期为 `1`；没有完成新匹配时为 `0`。每完成一次匹配，`count` 加一。`count` 达到 3 后保持为 3，但后续匹配仍须正常产生 `hit`。

检测允许重叠。例如输入 `1101101` 时，第 1～4 位与第 4～7 位分别构成一次 `1101`，因此第 4、7 次采样后都应出现一次 `hit=1`，`count` 依次变为 1、2。

`reset` 只在时钟上升沿生效。复位有效的上升沿须清空检测状态、`hit` 和 `count`，且该周期的 `din` 不参与检测。

### 我的思路

MOORE机，检测字符串1101，检测到的话hit置高一周期，同步复位，
输出为hit和count[1:0],count为成功检测次数，最高为3，计数到3之后不会再变化

## T3 打印机使用安排

同学 A 和 B 共用一台打印机，同一时刻最多安排一人打印。请使用 Logisim 设计一个 **Mealy 型有限状态机**，根据当前申请和此前完成的打印记录，决定本次由谁使用打印机。

### 输入输出

| 名称 | 方向 | 位宽 | 含义 |
| --- | --- | ---: | --- |
| `clk` | 输入 | 1 位 | 在上升沿记录本次打印 |
| `reset` | 输入 | 1 位 | 高电平有效的异步复位 |
| `reqA` | 输入 | 1 位 | A 是否申请打印，`1` 表示申请 |
| `reqB` | 输入 | 1 位 | B 是否申请打印，`1` 表示申请 |
| `grant` | 输出 | 2 位 | `00`：无人打印；`01`：A 打印；`10`：B 打印 |

`grant` 由当前申请和此前的打印记录共同决定，不能输出 `11`：

1. 两人都不申请时，输出 `00`。
2. 只有一人申请时，安排该申请者，即使此人此前已连续打印两次或更多次。
3. 两人都申请、且复位后尚无人打印时，安排 A。
4. 两人都申请、且已有打印记录时：若最近打印的人只连续打印过一次，继续安排此人；若已连续打印至少两次，安排另一人。

在每个时钟上升沿，有申请且被 `grant` 选中的人完成一次打印，此时更新“最近打印的人”和“连续打印次数”。无人打印的周期保留原有记录；换人打印后，连续次数从一次重新计算。因此，空闲周期不会打断某人的连续打印记录。

仿真开始时，打印记录为空。`reset=1` 时须立即清空并保持该记录，期间的时钟上升沿不计入打印次数；但 `grant` 仍根据当前申请和空记录计算。例如复位期间两人都申请，`grant` 应为 `01`。

例如，复位结束后 A、B 始终同时申请，前八次的 `grant` 应依次为 `01、01、10、10、01、01、10、10`。

### 我的思路

MEALY机

## 经验
有限状态机用ROM比较方便

举个例子:navigation这道题

![](/img/posts/p0/navagation.png)

ROM可以理解为一张提前填好的查找表：输入作为地址，输出就是该地址中保存的数据。因此，只要列出“当前状态＋当前输入”对应的“下一状态＋下一输出”，就可以用ROM代替复杂的状态转移逻辑。

以navigation为例，5个位置需要3位状态编码，方向dir占2位。将它们拼接成ROM的5位地址：

```text
地址[4:2] = 当前状态state
地址[1:0] = 当前方向dir
```

也就是：

```text
地址 = state × 4 + dir
```

因此，同一个状态对应连续4个地址，分别填写向北、向东、向南、向西时的结果。5位地址一共有32种组合，未使用的状态编码也可以统一填成回到初始状态。

ROM的数据中保存下一状态和下一周期的输出。这里可以约定：

```text
数据[4:2] = next_state
数据[1]   = next_arrive
数据[0]   = next_hit
```

所以数据位宽也是5位，填写的数值为：

```text
数据 = next_state × 4 + next_arrive × 2 + next_hit
```

例如，某个地址对应“下一状态为010，没有到达，但撞墙”，应填写：

```text
01001₂ = 09₁₆
```

连线时，状态寄存器的Q端与dir一起接到ROM地址端；ROM输出通过Splitter拆开，分别接到状态寄存器、arrive寄存器和hit寄存器的D端。这三个寄存器使用同一个时钟。

ROM只负责组合逻辑，不会自己记住状态。时钟上升沿到来时，寄存器才把ROM算出的结果保存下来：

```text
当前状态＋方向 → ROM查表 → 下一状态、下一输出
                              ↓ 时钟上升沿
                           寄存器更新
```

撞墙时，表中填写“下一位置保持不变、next_hit=1”；正常移动时填写新位置，并令next_hit=0。进入B时令next_arrive=1；当前处于B时，无论dir是什么，都填写“回到A、两个输出清零”，这样就能忽略返回周期的输入。

由于hit和arrive都经过寄存器保存，输出不会随着dir的变化立即改变。严格来说，位置、hit和arrive这些寄存器共同构成完整状态，因此仍然可以实现Moore型状态机。
